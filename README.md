# Guia Turístico de Lisboa
Website turístico desenvolvido em HTML5 e CSS3 durante a formação em programação, apresentando informações sobre história, cultura, gastronomia e locais turísticos de Lisboa.

## Funcionalidades
- Página inicial com apresentação de Lisboa
- Secção de história e dados demográficos
- Tabela de informações sobre a cidade
- Lista de locais turísticos
- Curiosidades de A a Z
- Conteúdo sobre cultura e eventos
- Secção de gastronomia
- Conteúdo multimédia
- Vídeos incorporados
- Áudio
- Mapa interativo
- Galeria de imagens
- Formulário de contacto
- Informações adicionais no formulário
- Navegação entre diferentes secções

## Tecnologias
- HTML5
- CSS3

## Principais conceitos aplicados
- HTML semântico
- Estruturação de páginas web
- Formulários HTML
- Tabelas
- Listas ordenadas e não ordenadas
- Links internos e externos
- Imagens e multimédia
- Vídeos através de iframe
- Áudio HTML5
- Google Maps através de iframe
- Galeria de imagens
- CSS Grid
- Flexbox
- Design responsivo
- Media Queries
- Pseudo-classes
- Variáveis CSS
- Meta tags e Open Graph
